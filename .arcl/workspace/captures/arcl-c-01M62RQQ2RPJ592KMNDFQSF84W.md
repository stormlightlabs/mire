The focus mode board lists the terminal keys `{ }` hunk, `p P` note, `c` note on this line, `1 2` unified or split, and `w` wrap. The web review supports `[ ]`, `j k` (findings), `b` and `Esc`; focus mode lists only those. Add the rest to the web review and its key bar: hunk jumps, `p`/`P` as finding aliases, `1`/`2` for the layout buttons, wrap, and a note on the current line once the web can create notes.
